# テスト項目書

本プロジェクトの自動テストの一覧。`mvn test`で実行される全テストケースを対象とする。

## 前提

| 項目 | 内容 |
| --- | --- |
| 実行コマンド | `mvn test` |
| テストフレームワーク | JUnit 5 / Mockito |
| 総件数 | 74件（単体テスト66件 / 結合テスト8件） |
| Checkstyle | 違反0件 |

## 分類の定義

| 分類 | 定義 |
| --- | --- |
| 正常系 | 仕様どおりの入力に対し、期待する結果が返ることを確認する |
| 業務エラー系 | 業務仕様を満たさない入力に対し、**例外をスローせずエラー応答や既定値を返す**ことを確認する |
| システムエラー系 | 入力の形式不正や通信・基盤の異常により、**例外がスローされる／捕捉される**ことを確認する |

## 4. 補足

- 結合テストではシステムエラー系を扱っていない。ソケットのタイムアウト・`IOException`など基盤レベルの異常は、`TcpConnectionHandler`の単体テスト（#42・#43）でモックを用いて検証している。
- `TcpServer`は単体テストを持たない。サーバーソケットの生成・スレッドプールの管理が主責務であり、`TcpSocketIntegrationTest`が実際にサーバーを起動して疎通を検証することで代替している。
